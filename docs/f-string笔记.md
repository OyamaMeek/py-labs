# Python f-string 详细笔记

本笔记结合 [`work/3-261102/4.py`](../work/3-261102/4.py) 的商品信息输出练习，示例适用于项目的 Python 3.9.6。标有 `>>>` 的内容表示交互式输入，不需要把 `>>>` 一起复制到 `.py` 文件；后面的行是实际输出。

## 1. f-string 的作用

f-string 的全称是 formatted string literal，即“格式化字符串字面量”。在字符串引号前加 `f`，就可以在 `{}` 中放入变量或表达式，并控制显示格式。基本语法可参阅 [Python 官方教程](https://docs.python.org/3.9/tutorial/inputoutput.html#formatted-string-literals)。

```pycon
>>> name = "小明"
>>> age = 18
>>> print(f"我叫{name}，今年{age}岁。")
我叫小明，今年18岁。

```

`f` 和 `F` 都可以，通常使用小写 `f`；单双引号都可以。

f-string 的结果是字符串，`print()` 负责把它输出。也可以先把结果保存到变量中：

```pycon
>>> message = f"姓名：{name}，年龄：{age}"
>>> print(message)
姓名：小明，年龄：18
>>> type(message)
<class 'str'>

```

不加 `f` 时，花括号和变量名会按原样显示：

```pycon
>>> print("姓名：{name}")
姓名：{name}

```

## 2. 从当前题目理解完整写法

原代码：

```python
name = input()
price = float(input())
quantity = int(input())
print(f"{name:<10} {price:>8.2f} {quantity:>3}")
```

`input()` 返回字符串，因此单价先转成 `float`，数量先转成 `int`。

| 部分 | 含义 |
| --- | --- |
| 引号前的 `f` | 启用 f-string，计算 `{}` 中的内容 |
| `{name:<10}` | 名称左对齐，最小宽度为 10，不足补空格 |
| `{price:>8.2f}` | 单价右对齐，最小宽度为 8，保留两位小数 |
| `{quantity:>3}` | 数量右对齐，最小宽度为 3 |
| 两组花括号之间的空格 | 额外输出一个分隔空格 |

用英文名称观察空格更直观：

```pycon
>>> name, price, quantity = "Apple", 5.5, 3
>>> print(f"{name:<10} {price:>8.2f} {quantity:>3}")
Apple          5.50   3
>>> row = f"{name:<10} {price:>8.2f} {quantity:>3}"
>>> len(row)
23
>>> print(row.replace(" ", "·"))
Apple··········5.50···3

```

最后一行把实际空格替换成 `·`，方便数空格。原输出中没有这些圆点。

这一行在内容没有超出列宽时，长度为 `10 + 1 + 8 + 1 + 3 = 23`。`print()` 还会在末尾输出换行符，这个换行符不属于变量 `row`。

**两个 `f` 的作用不同：**引号前的 `f` 标记字符串；`.2f` 中的 `f` 指定定点小数格式。

## 3. 花括号中的基本结构

常见写法是 `{表达式:格式说明}`；不需要设置格式时，省略冒号及其后面的内容。

```pycon
>>> price = 5.5
>>> print(f"{price}")
5.5
>>> print(f"{price:.2f}")
5.50

```

读 `{price:>8.2f}` 时，按下面的顺序理解：

1. `price`：需要显示的值。
2. `:`：开始指定格式。
3. `>`：右对齐。
4. `8`：整个格式化结果至少占 8 个字符位置。
5. `.2`：小数点后显示 2 位。
6. `f`：按定点小数格式显示。

对于这里的字符串和数字，冒号后常用选项的顺序是“填充与对齐、符号、进制前缀、补零、宽度、分组、精度、类型”；每项按需使用。完整规则见 [Python 格式说明文档](https://docs.python.org/3.9/library/string.html#format-specification-mini-language)。

## 4. 对齐：`<`、`>`、`^`

| 符号 | 含义 | 空余位置在哪里 |
| --- | --- | --- |
| `<` | 左对齐 | 右边 |
| `>` | 右对齐 | 左边 |
| `^` | 居中对齐 | 两边 |

示例中的竖线是主动加上的边界标记，用于观察空格：

```pycon
>>> word = "cat"
>>> print(f"|{word:<7}|")
|cat    |
>>> print(f"|{word:>7}|")
|    cat|
>>> print(f"|{word:^7}|")
|  cat  |

```

这些符号位于冒号之后时表示格式对齐；放在普通 Python 表达式里时，`<`、`>` 仍然可以表示大小比较：

```pycon
>>> print(f"{3 > 2}")
True

```

## 5. 宽度是最小宽度

宽度不足时补字符；内容过长时完整显示，不会自动截断。

```pycon
>>> print(f"|{123:>5}|")
|  123|
>>> print(f"|{123456:>5}|")
|123456|

```

数字的宽度包含负号、小数点、分隔符和进制前缀等。例如 `-5.50` 本身有 5 个字符：

```pycon
>>> print(f"|{-5.5:>8.2f}|")
|   -5.50|

```

省略对齐符号时，字符串通常默认左对齐，数字通常默认右对齐。初学时明确写出 `<` 或 `>` 更容易阅读。

```pycon
>>> print(f"|{'cat':7}|")
|cat    |
>>> print(f"|{12:7}|")
|     12|

```

## 6. 自定义填充字符

在对齐符号前写一个填充字符，替代默认空格。例如 `*<7` 表示“用 `*` 填充、左对齐、最小宽度为 7”。

```pycon
>>> print(f"{'cat':*<7}")
cat****
>>> print(f"{'cat':->7}")
----cat
>>> print(f"{'cat':_^7}")
__cat__

```

填充字符通常只写一个，并且紧挨对齐符号。

## 7. 小数：`.2f`

`.nf` 表示按定点小数格式显示，小数点后保留 `n` 位；不足补零，超过时进行舍入。

```pycon
>>> number = 12.3456
>>> print(f"{number:.0f}")
12
>>> print(f"{number:.1f}")
12.3
>>> print(f"{number:.2f}")
12.35
>>> print(f"{5:.2f}")
5.00
>>> print(f"{5.5:f}")
5.500000

```

对于 `float`，只写 `f` 默认显示 6 位小数。`.2f` 指小数点后的位数，不表示整个数字只占两位。

格式化得到新的字符串，原数值保持不变：

```pycon
>>> value = 3.14159
>>> text = f"{value:.2f}"
>>> print(text)
3.14
>>> print(value)
3.14159

```

**舍入注意：**`float` 使用二进制近似表示很多十进制小数，不应把格式化理解为总能得到十进制手算的“四舍五入”结果。

```pycon
>>> print(f"{2.675:.2f}")
2.67
>>> print(f"{2.5:.0f}")
2
>>> print(f"{3.5:.0f}")
4

```

后两例展示恰好处于中点时取偶数的舍入结果。严格的十进制金额计算需要根据业务规则使用 `Decimal`；加 `.2f` 只改变显示，不能修正之前的计算误差。

## 8. 整数、补零和正负号

### 8.1 `d`：十进制整数

```pycon
>>> count = 23
>>> print(f"{count:d}")
23
>>> print(f"|{count:5d}|")
|   23|

```

### 8.2 `05d`：补零到至少 5 位

```pycon
>>> print(f"{23:05d}")
00023
>>> print(f"{-23:05d}")
-0023
>>> print(f"{123456:05d}")
123456

```

`0` 指定数字的符号感知补零：负号保留在最前面，零补在负号和数字之间。宽度 5 包含负号。

### 8.3 `+`：正数也显示符号

```pycon
>>> print(f"{12:+d}")
+12
>>> print(f"{-12:+d}")
-12
>>> print(f"{12:+06d}")
+00012
>>> print(f"|{12: d}|")
| 12|

```

`+` 表示正负数都显示符号；空格符号选项表示正数前留一个空格、负数前显示负号。默认只显示负号。

## 9. 千位分隔符和百分比

### 9.1 `,` 与 `_`：数字分组

```pycon
>>> print(f"{1234567:,}")
1,234,567
>>> print(f"{1234567.8:,.2f}")
1,234,567.80
>>> print(f"{1234567:_}")
1_234_567

```

`,` 放在宽度之后、精度之前。例如 `>15,.2f` 表示右对齐、最小宽度 15、千位逗号分组、两位小数。

### 9.2 `%`：乘以 100 并显示百分号

```pycon
>>> ratio = 0.856
>>> print(f"{ratio:.1%}")
85.6%
>>> print(f"{ratio:.2%}")
85.60%
>>> print(f"{85.6:.1%}")
8560.0%

```

如果原值已经是 `85.6`，只需在普通小数格式之后添加字面百分号：

```pycon
>>> print(f"{85.6:.1f}%")
85.6%

```

## 10. 科学计数法、有效数字和进制

### 10.1 `e` 与 `g`

```pycon
>>> print(f"{12345.678:.2e}")
1.23e+04
>>> print(f"{12345.678:.4g}")
1.235e+04
>>> print(f"{12.3456:.4g}")
12.35

```

`.2e` 表示科学计数法中小数点后 2 位；`.4g` 表示 4 位有效数字，并根据数值大小选择普通小数或科学计数法。它们与 `.4f` 的含义不同。

### 10.2 `b`、`o`、`x`、`X`

```pycon
>>> number = 255
>>> print(f"{number:b}")
11111111
>>> print(f"{number:o}")
377
>>> print(f"{number:x}")
ff
>>> print(f"{number:X}")
FF
>>> print(f"{number:#x}")
0xff
>>> print(f"{number:#b}")
0b11111111

```

`b` 是二进制，`o` 是八进制，`x` 和 `X` 是十六进制。`#` 在这些进制格式中添加相应前缀。

## 11. 花括号中可以写表达式

可以进行运算、调用函数、访问列表和字典，也可以使用条件表达式。

```pycon
>>> price, quantity = 5.5, 3
>>> print(f"总价：{price * quantity:.2f}")
总价：16.50
>>> print(f"名字长度：{len('Apple')}")
名字长度：5
>>> items = ["苹果", "香蕉"]
>>> print(f"第一项：{items[0]}")
第一项：苹果
>>> student = {"name": "小明", "score": 86}
>>> print(f"{student['name']}：{student['score']}分")
小明：86分
>>> score = 86
>>> print(f"结果：{'及格' if score >= 60 else '不及格'}")
结果：及格

```

Python 3.9 中，表达式里的引号要避免与最外层引号冲突；例如外层双引号、字典键使用单引号。复杂计算可以提前放到变量中，让输出语句保持清楚。

## 12. 花括号、换行和多行字符串

### 12.1 输出花括号本身

在 f-string 的普通文本部分，用 `{{` 输出 `{`，用 `}}` 输出 `}`。

```pycon
>>> print(f"集合写法：{{1, 2, 3}}")
集合写法：{1, 2, 3}
>>> name = "小明"
>>> print(f"{{{name}}}")
{小明}

```

`{{{name}}}` 中，外面的 `{{` 和 `}}` 输出花括号，中间的 `{name}` 替换变量。

### 12.2 换行与多行

```pycon
>>> print(f"姓名：{name}\n年龄：{18}")
姓名：小明
年龄：18
>>> message = f"""姓名：{name}
... 年龄：{18}"""
>>> print(message)
姓名：小明
年龄：18

```

`\n` 是换行；三引号允许直接保留换行。多行字符串中写进去的缩进也可能成为实际内容。

## 13. 调试写法：`=`、`!s`、`!r`、`!a`

### 13.1 `{变量=}`

Python 3.8 起支持同时显示表达式文本和结果，项目 Python 3.9 可以使用。

```pycon
>>> quantity = 3
>>> price = 5.5
>>> print(f"{quantity=}")
quantity=3
>>> print(f"{price * quantity=}")
price * quantity=16.5
>>> print(f"{price=:.2f}")
price=5.50

```

调试输出会保留表达式附近的空格；有固定输出要求的练习只在题目需要时使用它。

### 13.2 `!s`、`!r`、`!a`

| 写法 | 对应转换 | 常见用途 |
| --- | --- | --- |
| `{value!s}` | `str(value)` | 转成普通可读字符串 |
| `{value!r}` | `repr(value)` | 查看引号、换行和其他转义细节 |
| `{value!a}` | `ascii(value)` | 用转义形式表示非 ASCII 字符 |

```pycon
>>> text = "A\nB"
>>> print(f"{text!s}")
A
B
>>> print(f"{text!r}")
'A\nB'
>>> print(f"{'中'!a}")
'\u4e2d'

```

可以继续添加格式说明，例如 `{text!r:>12}`：先转换，再按字符串进行对齐。转换字段和调试语法详见 [f-string 语言参考](https://docs.python.org/3.9/reference/lexical_analysis.html#formatted-string-literals)。

## 14. 动态指定宽度与精度

格式说明中还可以引用变量：

```pycon
>>> value = 12.3456
>>> width = 10
>>> precision = 2
>>> print(f"|{value:>{width}.{precision}f}|")
|     12.35|

```

这里 `{width}` 替换为 `10`，`{precision}` 替换为 `2`，最终采用 `>10.2f`。普通练习宽度固定时，直接写数字即可。

## 15. 日期也可以格式化

日期对象的冒号后采用日期格式规则：

```pycon
>>> from datetime import datetime
>>> moment = datetime(2026, 11, 3, 9, 5, 7)
>>> print(f"{moment:%Y-%m-%d %H:%M:%S}")
2026-11-03 09:05:07

```

这里 `%Y`、`%m`、`%d` 分别表示年、月、日，`%H`、`%M`、`%S` 分别表示时、分、秒。日期规则由日期对象解释，不同类型的格式说明可以不同。

## 16. 常见错误与边界情况

### 16.1 把字符串当作数字格式化

```pycon
>>> price = "5.5"
>>> print(f"{price:.2f}")
Traceback (most recent call last):
...
ValueError: Unknown format code 'f' for object of type 'str'
>>> print(f"{float(price):.2f}")
5.50

```

来自 `input()` 的内容需要先按题意转换类型。

### 16.2 给浮点数使用整数格式 `d`

```pycon
>>> print(f"{3.5:d}")
Traceback (most recent call last):
...
ValueError: Unknown format code 'd' for object of type 'float'

```

需要显示零位小数时可以用 `.0f`。只有题目确实要求转换为整数时才使用 `int()`，因为转换会截去小数部分。

### 16.3 混淆宽度与精度

| 写法 | 含义 |
| --- | --- |
| `{value:8}` | 最小宽度 8 |
| `{value:.2f}` | 小数点后 2 位 |
| `{value:8.2f}` | 最小宽度 8，小数点后 2 位 |
| `{value:08.2f}` | 最小宽度 8，数字补零，小数点后 2 位 |

```pycon
>>> print(f"{5.5:08.2f}")
00005.50

```

### 16.4 字符串精度表示截取长度

```pycon
>>> title = "Python"
>>> print(f"{title:.3s}")
Pyt
>>> print(f"|{title:>8.3s}|")
|     Pyt|

```

对字符串使用 `.3s` 会最多保留前 3 个字符；对整数使用 `.2d` 则是无效格式。

### 16.5 中文字符与屏幕宽度

```pycon
>>> name = "苹果"
>>> len(name)
2
>>> print(f"{name:<10}".replace(" ", "·"))
苹果········

```

这里补 8 个空格。对字符串，Python 根据 Unicode 码点数量计算这种格式宽度；中文在很多终端中每个字显示为两列，emoji、组合字符和字体也会影响显示。因此中英文混排时，屏幕上不一定整齐。当前题目按要求使用 `<10` 即可，不能把显示列宽直接当作格式宽度。

### 16.6 f-string 创建后不会自动更新

```pycon
>>> count = 1
>>> message = f"数量：{count}"
>>> count = 2
>>> print(message)
数量：1

```

表达式在执行到 f-string 时计算，生成的字符串保存当时的结果。

### 16.7 括号和变量名

- `{}` 中不能留空，花括号需要配对，否则会出现 `SyntaxError`。
- 使用尚未定义的变量会出现 `NameError`。
- Python 3.9 不支持在替换表达式内部写反斜杠或注释；需要换行分隔符时，先将它保存为变量再引用。字符串普通文本中的 `\n` 可以正常使用。

## 17. 常用写法速查

表中的 `x` 分别取“示例值”，各行独立理解。

| 写法 | 示例值 | 结果 | 用途 |
| --- | --- | --- | --- |
| `f"{x}"` | `23` | `23` | 直接插入 |
| `f"{x:<6}"` | `"cat"` | `cat` 后补 3 个空格 | 左对齐 |
| `f"{x:>6}"` | `"cat"` | 前补 3 个空格，再输出 `cat` | 右对齐 |
| `f"{x:^7}"` | `"cat"` | 两边各补 2 个空格 | 居中 |
| `f"{x:.2f}"` | `5.5` | `5.50` | 两位小数 |
| `f"{x:08.2f}"` | `5.5` | `00005.50` | 数字补零 |
| `f"{x:05d}"` | `23` | `00023` | 整数编号 |
| `f"{x:+d}"` | `23` | `+23` | 显示正号 |
| `f"{x:,}"` | `1234567` | `1,234,567` | 千位分组 |
| `f"{x:.1%}"` | `0.856` | `85.6%` | 百分比 |
| `f"{x:.2e}"` | `12345` | `1.23e+04` | 科学计数法 |
| `f"{x:.4g}"` | `12.3456` | `12.35` | 有效数字 |
| `f"{x:#x}"` | `255` | `0xff` | 十六进制 |
| `f"{x=}"` | `23` | `x=23` | 调试 |

## 18. 自测练习与答案

先独立写出表达式，再运行核对。

1. `name = "Bob"`，左对齐到宽度 8，用 `-` 填充。
2. `price = 9.5`，右对齐到宽度 8，保留两位小数。
3. `number = 42`，显示为四位编号，不足补零。
4. `ratio = 0.875`，显示为带一位小数的百分比。
5. `price = 3.5`、`quantity = 4`，输出 `总价：14.00元`。
6. `name = "Bob"`，输出 `{Bob}`，保留两侧花括号。

参考答案：

```pycon
>>> name = "Bob"
>>> print(f"{name:-<8}")
Bob-----
>>> price = 9.5
>>> print(f"|{price:>8.2f}|")
|    9.50|
>>> number = 42
>>> print(f"{number:04d}")
0042
>>> ratio = 0.875
>>> print(f"{ratio:.1%}")
87.5%
>>> price, quantity = 3.5, 4
>>> print(f"总价：{price * quantity:.2f}元")
总价：14.00元
>>> print(f"{{{name}}}")
{Bob}

```

第二题答案中的竖线用于观察边界，实际题目没有要求时可以去掉。
